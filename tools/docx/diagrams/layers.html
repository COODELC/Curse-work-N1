Представление (Views, XAML)
MainWindow — каталог товаров, поиск, фильтр по категориям, корзина
ProductDetailsWindow — карточка товара, описание, отзывы
CartWindow — состав корзины, итоговая сумма, оформление
ReviewsWindow / ReviewWindow — список отзывов и форма отзыва
OrdersWindow — мои заказы
ManagerWindow — обработка заказов сотрудником
AdminWindow — управление товарами, категориями, пользователями
ProfileWindow / RolesWindow — профиль пользователя и роли
Модель представления (ViewModels)
MainViewModel — каталог, поиск, фильтрация, добавление в корзину, команды переходов
CartViewModel — позиции корзины и пересчёт суммы
OrdersViewModel — загрузка истории заказов пользователя
ManagerViewModel — все заказы, смена статуса, отмена заказа
AdminViewModel / RolesViewModel — управление данными каталога и ролями
Сервисы предметной области (Services)
OrderService — оформление заказа, скидка 25 %, списание остатка, смена статуса, отмена с возвратом
ItemService — каталог товаров, категории, отзывы товара
CategoryService — справочник категорий
ReviewService — добавление отзыва с фиксацией автора
CatalogAdminService — изменение состава каталога
AuthService — вход, проверка пароля, роли и права
Доступ к данным (Data)
DbFactory — выбор SQL Server / SQLite по строке подключения
WorkshopDbContext — 7 таблиц, 7 внешних ключей
SchemaUpgrade — обновление схемы (ALTER TABLE, FK)
SeedData — справочники и демонстрационные данные
